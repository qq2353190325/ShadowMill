影坊 ShadowMill

一站式音视频创作流水线：内容脚本 → 配音 → 字幕 → HTML 动画 → 视频。 语音识别与视频渲染都在本机完成，不消耗 API 额度。

下载 Windows 版

文件：—

  • 系统要求：Windows 10 / 11（64 位）。macOS 版本尚未发布。
  • 安装包不含渲染运行环境（ffmpeg / hyperframes，两个包合计约 146 MB）：首次用到「转成视频 / 提取原声 / 逐句对齐」时，应用会先问你要不要下载，确认后才开始，可取消。
  • 语音识别（whisper-cli.exe）随安装包，装完即可离线转录；识别模型需在应用内按需下载。
  • 首次使用请到「设置」页填写自定义模型与千问语音 API Key。
